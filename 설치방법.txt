 POS Middleware 설치 방법 (Windows 포스기용)
============================================================

[1] 다운로드
  GitHub 저장소 → Actions 탭 → 가장 최근 성공한 실행(run) 선택
  → 하단 Artifacts 에서 'pos-middleware-package' 다운로드 → 압축 해제

  압축을 풀면 다음 3개가 들어 있습니다:
    pos-middleware.exe   ← 실행 파일
    config.json         ← 설정 파일
    설치방법.txt         ← 이 설명서

  ※ exe는 파이썬이 없어도 단독으로 실행됩니다.

[2] 프린터 IP 확인 (포스기마다 1번씩)
  프린터 3대는 각각 다른 IP를 가지고 있고, 각 포스기에 등록되어 있습니다.

  1) 포스기에서: 제어판 → 장치 및 프린터
  2) 사용 중인 영수증 프린터 우클릭 → 프린터 속성 → 포트 탭
  3) '표준 TCP/IP 포트'에 적힌 IP 주소 확인 (예: 192.168.0.10)

  이 IP가 "이 포스기"가 사용하는 프린터의 주소입니다.
  3대 모두 각각의 포스기에서 같은 방법으로 확인합니다.

[3] config.json 수정 (메모장으로 열어 수정)
  "printer"의 "ip" 값을 [2]에서 확인한 프린터 IP로 변경합니다.

    {
      "printer": { "ip": "192.168.0.10", "port": 9100 },   ← 이 부분
      "listen":  { "host": "127.0.0.1", "port": 9100 },
      "debug": false
    }

  - port는 보통 9100입니다 (포트 탭에서 확인 가능).
  - debug를 true로 바꾸면 상세 로그가 화면과 log.txt에 남습니다.

[4] 포스 프로그램(또는 Windows 프린터)의 프린터 주소 변경
  인쇄가 미들웨어를 거치도록 주소를 이 컴퓨터 자신(127.0.0.1)으로 바꿉니다.
  둘 중 해당하는 방법으로:

  A) 포스 프로그램 안에서 프린터 IP를 직접 설정하는 경우
     → 프린터 IP를 127.0.0.1 로 변경 (포트 9100 유지)

  B) Windows 프린터 드라이버를 통해 출력하는 경우
     → 제어판 → 장치 및 프린터 → 프린터 속성 → 포트 탭
     → '표준 TCP/IP 포트'의 IP 주소를 127.0.0.1 로 변경 (포트 9100 유지)

[5] 실행
  pos-middleware.exe 더블클릭 → 아래 메시지가 보이면 정상입니다:

    === POS Middleware 시작 (네트워크 릴레이 모드) ===
    [대기] 수신 서버 시작: 127.0.0.1:9100

  ※ 창을 닫으면 미들웨어도 종료됩니다.
    매장 영업시간 동안 켜 두세요. (아래 [7] 참고)

[6] 시험 인쇄
  1) 홀 주문 1건 인쇄 → 원본 그대로 출력되어야 함
  2) 배달 주문 1건 인쇄 → 영수증 하단에 '--- 부자재 목록 ---' 추가 출력
     (단, [고객용] 영수증은 원본 그대로)

[7] 자동 시작 설정 (권장)
  포스기를 켤 때 자동 실행되도록 등록:
  1) Win + R → shell:startup 입력 → 엔터
  2) 열린 폴더에 pos-middleware.exe 바로가기를 복사

[8] 문제 발생 시
  - exe와 같은 폴더의 log.txt에 처리 내역/오류가 기록됩니다.
  - config.json의 debug를 true로 바꾸면 상세 로그가 남습니다.
